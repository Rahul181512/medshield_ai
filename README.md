# medshield_ai
An AI-powered PHI/PII Redaction Pipeline designed to protect sensitive healthcare data before it is sent to Large Language Models (LLMs).

## Features (Planned)

- FastAPI Backend
- Streamlit Frontend
- JWT Authentication
- Role-Based Access Control
- Regex + NLP Detection
- PHI/PII Redaction
- Pseudonymization
- Redis Mapping Vault
- Audit Logging
- Evaluation Metrics
